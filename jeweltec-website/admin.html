Editing Guide

          
Everything is edited by hand, in plain files — no database, no CMS.

        

      


      

        

          
Add / Edit a Product

          
Open assets/js/products-data.js. Every product is one JavaScript object inside the PRODUCTS array. Copy an existing one to add a product, or edit any field directly to update it — name, price, description, images, and so on.

        

        

          
Remove a Product

          
Delete its whole { ... } block (including the trailing comma) from the PRODUCTS array in the same file.

        

        

          
Mark Sold / Feature a Product

          
Change available: true to available: false, or featured to true / false, on that product's entry.

        

        

          
Replace a Product Image

          
Upload the new photo into assets/images/products/, then update the image and gallery fields to point at the new filename(s).

        

      


      
Example product entry

      
{
  id: 19,
  name: "Heritage Gold Drop Earrings",
  category: "WOKO",
  price: 65000,
  available: true,
  featured: false,
  image: "assets/images/products/product-19.jpg",
  gallery: ["assets/images/products/product-19.jpg"],
  shortDescription: "Delicate gold drop earrings finished by hand.",
  description: "A longer paragraph describing the piece in full.",
  materials: "18k solid gold",
  occasions: "Everyday wear, gifting",
  care: "Wipe clean after wear; store in a dry pouch."
},


      

        No database, no CMS, no auto-sync — by design. Every jewelry piece Jeweltec sells is handcrafted and changes by hand, so the catalog is a plain, readable file you fully control. Changes take effect the moment you save the file and re-upload it to your web host.
